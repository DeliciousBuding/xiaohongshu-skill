# 集成示例

本目录包含 xiaohongshu-skill 在不同平台/场景下的集成配置示例。

| 目录 | 说明 |
|------|------|
| `claude-code/` | Claude Code MCP 集成配置 |
| `cursor/` | Cursor agent shell 示例 |
| `demo/` | 公开展示用合成 JSON，不含真实账号数据 |
| `n8n/` | n8n Execute Command 节点示例 |
| `openclaw/` | OpenClaw 和 ClawHub 安装示例 |

更多集成方式（Docker、系统服务等）欢迎贡献。
