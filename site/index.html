Xiaohongshu Skill for AI Agents

Search Xiaohongshu and RedNote, read note details, prepare posts, and run browser automation from agents through one Python Playwright CLI.

Install View Demos 
pip install git+https://github.com/DeliciousBuding/xiaohongshu-skill.git
playwright install chromium
xiaohongshu-skill qrcode --headless=false
xiaohongshu-skill --profile brand-a search "上海咖啡" --limit=3
xiaohongshu-skill selectors --owner=publish
xiaohongshu-skill contracts --command=search

Search

Keyword search with sort, type, time, scope, and location filters.

Read

Fetch note details, comments, user pages, and explore feed data as JSON.

Publish

Prepare image, video, Markdown-image, and long-form posts with user approval.

Operate

Use templates, daily limits, profiles, and SOP commands for repeatable agent workflows.

Install paths

clawhub install xiaohongshu-skill

docker compose run --rm xiaohongshu search "美食"

Safety model

Read commands can run directly. Write commands need user approval. The browser client keeps pacing and stops when Xiaohongshu asks for verification.
